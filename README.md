## 🌟 Vue d'ensemble du Projet

Ce dépôt regroupe trois projets d'analyse de données réalisés sous **R** et **Quarto**. Ils explorent un spectre large de techniques analytiques : de la manipulation de données à la création d'applications interactives, jusqu'aux algorithmes d'apprentissage non supervisé avancés (Clustering et Analyse Archétypale).

## 📂 Contenu détaillé du Repository

### 1️⃣ Projet Initial : Introduction à Quarto, Shiny & Tidyverse
- **Application Interactive :** Modélisation de la loi Gamma via `Shiny`.
- **Manipulation :** Utilisation de `Tidyverse` sur `mtcars`.
- **Régression & Stats :** Sorties professionnelles via `stargazer` et étude sur le jeu de données réel du Keno.

### 2️⃣ Analyse de Clustering avec R
*(D'après Flynt & Dean, 2016)*
- **Méthodes Algorithmiques :** Application du `K-means` et de la Classification Hiérarchique Ascendante (`CAH`).
- **Méthodes Paramétriques :** Model-Based Clustering (`mclust`) et Latent Class Analysis (`poLCA`).

### 3️⃣ Projet Archétype : From Spider-Man to Hero
- **Concept :** Représentation d'observations multivariées via l'algorithme `archetypes`.
- **Cas Pratiques :** Analyse géométrique de squelettes et compression d'image (réduction de dimensionnalité colorimétrique RGB via `NNLS`).
